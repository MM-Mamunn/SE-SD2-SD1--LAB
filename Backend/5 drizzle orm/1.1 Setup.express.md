# Set Up an Express App with CommonJS

## 1. Install Express

In your project folder, run:

```bash
npm install express
```

This installs Express so you can use it in your Node.js project with CommonJS.

## 2. Create `index.js`

Create a file named `index.js` in your project folder and add the following code:

```javascript
const express = require('express');
const app = express();
const port = 3000;

app.get('/', (req, res) => {
  res.send('Hello World!');
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

## 3. Run the Project

In the terminal, run:

```bash
node index.js
```

You should see this message:

```text
Example app listening on port 3000
```

## 4. Open the App

Open your browser and visit:

<http://localhost:3000>

The page should display:

```text
Hello World!
```
