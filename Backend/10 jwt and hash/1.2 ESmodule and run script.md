# Set Up an Express App with ES Modules

## 1. Install Express

In your project folder, run:

```bash
npm install express
```

## 2. Configure `package.json`

Make sure your `package.json` includes `"type": "module"`. This tells Node.js to use ES module syntax such as `import` and `export`.

```json
{
  "main": "index.js",
  "type": "module",
  "scripts": {
    "start": "node index.js",
    "dev": "node index.js"
  },
  "dependencies": {
    "express": "^5.2.1"
  }
}
```

If your existing `package.json` has other dependencies, keep them and add or update only the relevant fields.

## 3. CommonJS vs. ES Modules

- **CommonJS:** uses `require()` to import packages, for example `const express = require('express');`.
- **ES Modules:** uses `import` to import packages, for example `import express from 'express';`.

**Why use ES Modules?** It uses the standard JavaScript module syntax and is common in modern JavaScript projects. Since this project has `"type": "module"`, use `import` and `export` in your `.js` files.

## 4. Create `index.js`

Create a file named `index.js` in your project folder and add this code:

```javascript
import express from 'express';

const app = express();
const port = 3000;

app.get('/', (req, res) => {
  res.send('Hello World!');
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

## 5. Run the Project

Start the server with:

```bash
npm start
```

Or run the entry file directly:

```bash
node index.js
```

You should see:

```text
Example app listening on port 3000
```

## 6. Open the App

Open your browser and visit <http://localhost:3000>.

The page should display:

```text
Hello World!
```
